# Dragon English 100 - 極限暗記暗誦學習系統

> 基於日本漫畫《東大特訓班 / 龍櫻》英語名師原型——**竹岡廣信**之經典著作《Dragon English 基本英文100》（『ドラゴン・イングリッシュ基本英文100』）與「暗記暗誦法」精心設計打造的高效學習 Web 應用。

---

## 🌟 核心特色與四大模組

本系統徹底摒棄傳統死背單字卡（Flashcards）的被動學習，嚴格貫徹竹岡流的**「肌肉記憶與認知轉換工程」**：

```
┌─────────────────────────────────────────────────────────────────┐
│                      Dragon 100 Learning Cycle                  │
│                                                                 │
│  [1. 概念解構]  ──▶  [2. 影子跟讀]  ──▶  [3. 極限盲測默寫]  ──▶  [4. 骨架替換] │
│  語法骨架/思維      原音朗讀/連音節奏     3秒倒數/Diff比對     情境造句/筆記保存 │
└─────────────────────────────────────────────────────────────────┘
```

1. **Step 1: 概念解構視圖（Syntax & Logic Deconstruct）**
   - 提取標準母語骨架（如：`It would be [Adj] to [Action 1] and [Action 2].`）
   - **和文和訳（思考降解）對照：** 將複雜抽象的中文思維先降解為具體邏輯，再行英譯。
   - 核心文法精析與竹岡流「思維陷阱」避坑提示。

2. **Step 2: 影子跟讀音律模組（Shadowing & Cadence）**
   - 整合瀏覽器原生的 **Web Speech API**，提供道地的美式/英式發音。
   - **單一統一調速機制（保留原音與調速選單，移除獨立慢速）：**
     - 原音播放直接套用使用者所設定的個人化速度（預設為 1.00x）。
     - 點擊「⚙️ 調整速度」即可開啟符合現代影音播放器體驗的調速面板（參考自經典播放器介面）。
     - **超大即時倍速數值**（如 `1.00x`）。
     - **左右 `[-]` / `[+]` 圓形微調步進按鈕**（步進 ±0.05x）。
     - **連續平滑滑桿（Slider）**：支援 `0.30x ~ 2.00x` 連續精準調節。
     - **快速檔位膠囊鈕**：`0.50x 超慢清晰`、`0.75x 慢速拆解`、`1.00x 正常原速`、`1.25x 自然流利`、`1.50x 快速挑戰`、`2.00x 極限倍速`。
     - **「🔊 試聽此速度」即時發音驗證**，調整後立即聽到效果並持久化儲存。
   - 視覺化語音波浪動畫，提供**「3 次循環跟讀」**模式，定型發音神經肌肉。

3. **Step 3: 極限盲測默寫模組（Blind Recall Engine —— 核心殺手級功能）**
   - 隱藏英文，只保留中文語意，給予大腦高壓輸出刺激。
   - **3 秒破冰倒數：** 模擬真實跨國會話中「不假思索」的反應時差，在倒數內鍵入第一個字即觸發「瞬發神經反射達成」勳章。
   - **單字與字元級 Diff 比對器：**
     - 🟢 **綠色：** 完全匹配正確
     - 🔴 **紅色：** 拼寫錯誤或缺漏單字
     - 🟠 **橘色：** 標點、大小寫或介系詞警示
   - 支援「標準模式」與「嚴格模式（大小寫標點 100% 精準）」。

4. **Step 4: 骨架替換沙盒（Slot-Filling Sandbox —— 3 大實戰例句與原音朗讀）**
   - 鎖定核心文法骨架，**全面升級為 3 個實戰情境示範例句**（涵蓋職場工作、日常生活、溝通論述/決策建議等）。
   - **每個示範例句皆配備「🔊 朗讀原音」按鈕**，隨時聽取標準語速發音，深度強化情境替換感。
   - 提供自定義生活造句輸入區，一鍵儲存至個人專屬筆記本。

## 🎮 多元挑戰與進度系統

- 🟩 **10x10 全綠通關牆（Mastery Wall 1~100）：** 100 個矩陣方格視覺化刺激，目標是「點亮 100 盞綠燈」！
- ⚡ **Daily Sprint（每日 5 句衝刺）：** 依據艾賓浩斯間隔重複法，隨機精選 3 句新句 + 2 句溫故複習句，10 分鐘形成記憶閉環。
- 🏆 **Survival Mode（百句極限生存戰）：** 3 顆心心生命值，每題 20 秒極限盲打，錯一字扣心，連續答對啟動連勝分數加倍，挑戰歷史最高得分！
- 🔍 **句庫全文速查（Explorer & Filter）：** 100 句全文即時檢索、分類篩選、一鍵聽音與星號收藏。
- 🌓 **深色 / 淺色雙主題切換**，精美低摩擦終端機設計風格。
- 🔔 **Web Audio API 無依賴合成音效**（答對和弦、錯誤低音、倒數滴答聲）。
- 💾 **LocalFirst 離線優先架構：** 所有進度、收藏、自訂造句與錯題庫均即時自動儲存於瀏覽器 LocalStorage。
- 📱 **專屬手機極速掌中版 (`mobile.html`)：** 專門針對直式螢幕與單手大拇指人因工程設計，提供「3D 翻牌盲聽」、「免打字詞塊速拼」與「隨身聽連播」等極致行動體驗。

## 📱 手機極速掌中版 (`mobile.html`) 特色

專為智慧型手機（iOS Safari / Android Chrome 等）打造的輕量極速版本：

1. **🎧 翻牌盲聽卡（Flashcard Deck）**：
   - 正面大字中文 + 一鍵原音朗讀，支援左右滑動（Swipe）手勢換題、輕觸卡片 3D 翻面。
   - 背面標準英文、文法骨架，以及切換 **3 大實戰情境例句**（各附專屬朗讀按鈕）。
   - 底部單手大拇指按鈕：`✕ 還不熟練` 與 `✓ 通關點燈`。
2. **🧩 詞塊速拼（Chunk Tap Puzzle）**：
   - 徹底告別手機軟鍵盤長句盲打！自動將英文句子拆解為 4~6 個語法詞塊。
   - 單手點擊下方詞塊即時填入上方答案槽，完成瞬間秒級核對並播放原音。
3. **📻 隨身聽磨耳朵（Continuous Player）**：
   - 旋轉黑膠唱片風格視覺，支援 100 句循序連播、僅播收藏句或單句循環。
4. **⚙️ 底部滑出式調速與口音抽屜（Bottom Sheet）**：
   - 由螢幕下方滑出，隨時微調 `0.30x ~ 2.00x` 語速。
   - **新增口音切換**：支援一鍵切換 `🇺🇸 美式英語`、`🇬🇧 英式英語`、`🇦🇺 澳洲英語` 或選擇系統已安裝的特定語音角色，並附「`🔊 試聽`」按鈕。
5. **資料雙向無縫互通**：與桌機版共用瀏覽器 `localStorage`，通關進度、收藏星號、語速與口音偏好完全同步。
6. **📲 支援 PWA 桌面化**：手機瀏覽器開啟時可點擊「加入主畫面」，化身為全螢幕、無網址列干擾的獨立 App。

## 🌐 免費上傳 GitHub Pages 託管指南

本專案為 **100% 純靜態前端架構**，無須任何後端或資料庫即可永久免費託管：

1. **建立 GitHub 倉庫**：登入 GitHub，新增一個名為 `dragon-english-100` 的 Public 倉庫。
2. **上傳本專案檔案**：
   ```bash
   git init
   git add .
   git commit -m "feat: complete dragon english 100 web app"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/dragon-english-100.git
   git push -u origin main
   ```
   *(或直接在 GitHub 網頁端點選 "Upload files" 將資料夾內檔案全部拖曳上傳)*
3. **開啟 GitHub Pages**：
   - 進入倉庫的 **Settings** ➔ **Pages**。
   - 在 **Branch** 選取 `main` 分支與 `/ (root)` 資料夾，點擊 **Save**。
   - 約 30 秒後即可取得全球可存取的專屬 HTTPS 網址！
4. **手機加入桌面（PWA）**：
   - 用 iPhone Safari 開啟網址 ➔ 點擊底部「分享」按鈕 ➔ 選擇「**加入主畫面**」。
   - 用 Android Chrome 開啟網址 ➔ 點擊右上角三點選單 ➔ 選擇「**安裝應用程式 / 加入主畫面**」。

## ⌨️ 鍵盤高效快捷鍵 (桌機版適用)

| 快捷鍵 | 功能說明 |
| :--- | :--- |
| **Enter** | 提交盲測驗證 / Sprint 送出 / 生存戰送出 |

## 🚀 如何使用

1. 本專案為純原生前端架構（HTML5 + CSS3 + Vanilla JavaScript），**無須安裝 Node.js、npm 或任何後端伺服器**。
2. **桌機 / 平板完整版**：使用瀏覽器雙擊打開 **`index.html`**。
3. **手機掌中極速版**：在手機或以手機模式打開 **`mobile.html`**（或從桌機版右上角點擊「📱 手機專屬版」跳轉）。
