# Dragon English 100 - 極限暗記暗誦學習系統

> 基於日本漫畫《東大特訓班 / 龍櫻》英語名師原型——**竹岡廣信**之經典著作《Dragon English 基本英文100》（『ドラゴン・イングリッシュ基本英文100』）與「暗記暗誦法」精心設計打造的高效學習 Web 應用。

---

## 🌟 核心特色與四大模組

本系統徹底摒棄傳統死背單字卡（Flashcards）的被動學習，嚴格貫徹竹岡流的**「肌肉記憶與認知轉換工程」**：

```
┌─────────────────────────────────────────────────────────────────┐
│                      Dragon 100 Learning Cycle                  │
│                                                                 │
│  [1. 概念解構]  ──▶  [2. 影子跟讀]  ──▶  [3. 極限盲測默寫]  ──▶  [4. 骨架替換] │
│  語法骨架/思維      原音朗讀/連音節奏     3秒倒數/Diff比對     情境造句/筆記保存 │
└─────────────────────────────────────────────────────────────────┘
```

1. **Step 1: 概念解構視圖（Syntax & Logic Deconstruct）**
   - 提取標準母語骨架（如：`It would be [Adj] to [Action 1] and [Action 2].`）
   - **和文和訳（思考降解）對照：** 將複雜抽象的中文思維先降解為具體邏輯，再行英譯。
   - 核心文法精析與竹岡流「思維陷阱」避坑提示。

2. **Step 2: 影子跟讀音律模組（Shadowing & Cadence）**
   - 整合瀏覽器原生的 **Web Speech API**，提供純道地的美式/英式發音。
   - **獨立 0.5x 慢速按鈕（🐢 0.5x 慢速朗讀）：** 一鍵放慢語速，聽清母語人士每個連音（Linking）、弱讀（Reduction）與清音咬字細節。
   - 語速彈性切換：`0.5x（超慢清晰）`、`0.8x（慢速雕刻）`、`1.0x（標準語速）`、`1.2x（極速挑戰）`。
   - 視覺化語音波浪動畫，提供**「3 次循環跟讀」**模式，定型發音神經肌肉。

3. **Step 3: 極限盲測默寫模組（Blind Recall Engine —— 核心殺手級功能）**
   - 隱藏英文，只保留中文語意，給予大腦高壓輸出刺激。
   - **3 秒破冰倒數：** 模擬真實跨國會話中「不假思索」的反應時差，在倒數內鍵入第一個字即觸發「瞬發神經反射達成」勳章。
   - **單字與字元級 Diff 比對器：**
     - 🟢 **綠色：** 完全匹配正確
     - 🔴 **紅色：** 拼寫錯誤或缺漏單字
     - 🟠 **橘色：** 標點、大小寫或介系詞警示
   - 支援「標準模式」與「嚴格模式（大小寫標點 100% 精準）」。

4. **Step 4: 骨架替換沙盒（Slot-Filling Sandbox）**
   - 鎖定核心文法骨架，提供職場、日常與技術情境造句示範。
   - 使用者可輸入自定義生活造句，一鍵儲存至個人筆記本。

## 🎮 多元挑戰與進度系統

- 🟩 **10x10 全綠通關牆（Mastery Wall 1~100）：** 100 個矩陣方格視覺化刺激，目標是「點亮 100 盞綠燈」！
- ⚡ **Daily Sprint（每日 5 句衝刺）：** 依據艾賓浩斯間隔重複法，隨機精選 3 句新句 + 2 句溫故複習句，10 分鐘形成記憶閉環。
- 🏆 **Survival Mode（百句極限生存戰）：** 3 顆心心生命值，每題 20 秒極限盲打，錯一字扣心，連續答對啟動連勝分數加倍，挑戰歷史最高得分！
- 🔍 **句庫全文速查（Explorer & Filter）：** 100 句全文即時檢索、分類篩選、一鍵聽音與星號收藏。
- 🌓 **深色 / 淺色雙主題切換**，精美低摩擦終端機設計風格。
- 🔔 **Web Audio API 無依賴合成音效**（答對和弦、錯誤低音、倒數滴答聲）。
- 💾 **LocalFirst 離線優先架構：** 所有進度、收藏、自訂造句與錯題庫均即時自動儲存於瀏覽器 LocalStorage。

## ⌨️ 鍵盤高效快捷鍵

| 快捷鍵 | 功能說明 |
| :--- | :--- |
| **Enter** | 提交盲測驗證 / Sprint 送出 / 生存戰送出 |
| **Ctrl + Space** | 隨時播放當前句型原音朗讀 (1.0x) |
| **Ctrl + Alt + Space** | 隨時以 0.5 倍慢速朗讀當前句型 |
| **Tab** | 盲測輸入區中獲取首字母提示（Peek） |
| **Alt + 1 ~ 4** | 快速切換：1.解構 / 2.跟讀 / 3.盲測 / 4.造句 |
| **Alt + ← / →** | 切換至上一句 / 下一句 |

## 🚀 如何使用

1. 本專案為純原生前端架構（HTML5 + CSS3 + Vanilla JavaScript），**無須安裝 Node.js、npm 或任何後端伺服器**。
2. 直接使用現代瀏覽器（Google Chrome, Microsoft Edge, Safari, Firefox 等）雙擊打開目錄下的 **`index.html`** 即可立即開始學習！
